# Čtyři ateliérové kupičky

Vytvořeno vestavěným ImageGen podle přímého zadání Marka Stojky. Všechny čtyři snímky mají bílou scénu, stejné rozměry a podobnou pozici motivu. Popel vznikl první; jeho kompozice a osvětlení posloužily jako reference pro zbylé tři snímky. Jde o AI fotografie, nikoli reálně nafocené předměty. Kouř je součástí fotografie.

Projektové originály: `src/assets/piles/popel.png`, `pastelky.png`, `kreativec.png`, `banka.png`. Astro připravuje WebP varianty 540 a 1000 px. Všechny se zobrazují stejným způsobem bez individuálního ořezu nebo zvětšení. Původní Markovy kresby zůstávají uložené a mohou se využít později; současné hero používá výhradně tuto fotografickou sérii. Temná samostatná stránka s popelem se nemění.
